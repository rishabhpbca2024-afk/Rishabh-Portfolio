# Rishabh Pal — Personal Developer Portfolio

A modern, high-performance personal developer portfolio built for recruiters and engineering teams. Features verified full-stack project showcases, honest skill assessments, educational background from Sant Singaji Institute of Science and Management (SSISM), and secure communication channels.

---

## 🚀 Tech Stack

- **Frontend:** React 19, TypeScript
- **Styling:** Tailwind CSS (Modern dark developer palette: deep navy, charcoal, cyan accents)
- **Icons:** Lucide React & Custom SVG Icons
- **Bundler:** Vite
- **Code Quality:** Oxlint, TypeScript strict mode

---

## ✨ Key Highlights

- **Verified Project Architecture:** Detailed showcases of institutional platforms (Singaji Feedback System), mobile SQLite apps (Udhaari Manager), enterprise Java systems (Hospital Management System), Node.js backend systems (Vehicle Parking System), and full-stack MERN portals.
- **Recruiter-Centric Design:** Clean UI/UX, mobile responsive navigation, accessible color contrast, and instant resume downloading.
- **Zero Heavy Dependencies:** Fast, lightweight client-side rendering without external databases, paid APIs, or bloat.
- **Security Hardened:** Strict Content Security Policy (CSP), input sanitization, and safe external link handling (`rel="noopener noreferrer"`).

## 🛠️ Local Development

### Prerequisites
- Node.js (v18 or higher recommended)
- npm or yarn

### Installation & Run

1. Clone the repository:
   ```bash
   git clone https://github.com/rishabhpbca2024-afk/portfolio.git
   cd portfolio
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Start development server:
   ```bash
   npm run dev
   ```

4. Build for production:
   ```bash
   npm run build
   ```

5. Run linter:
   ```bash
   npm run lint
   ```
